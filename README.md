## This is the showcase of the neural network learns to solve the XOR problem

## Objective:
This project aims to enhance my mathematical understanding of neural network backpropagation through its implementation. The neural network uses the following settings for simplicity:

1. One backpropagation per sample with gradient descent.
2. Random initialization of weights and biases using a uniform distribution from -1 to 1.
3. Backpropagation implemented with the generalized delta rule, derived from the chain rule.
